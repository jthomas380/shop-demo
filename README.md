# North & Loom — Demo Storefront

North & Loom is a fictional apparel brand built as a portfolio project. It is a single-page storefront written in plain HTML, CSS, and JavaScript with no framework or build step.

Live demo: https://shop.jet380.com/

## Features

- Product grid with category filters, search, and sorting
- Quick-view product panel with color and size options
- Slide-out shopping bag with quantity controls, removal, and a demo promo code (WELCOME15)
- Three-step demo checkout (delivery, payment, confirmation)

## Demo notice

All products, prices, policies, and orders are fictional. The checkout does not send, store, or charge anything. Use test data only (for example, card number 4242 4242 4242 4242).

## Project files

- `index.html` – page layout and content
- `styles.css` – styling and responsive layout
- `app.js` – product data, filtering, cart, and checkout behavior
- `assets/` – product and hero images

## Deployment

The `main` branch deploys automatically to shop.jet380.com through Hostinger's GitHub integration.
